# Label guide

Every label in this repository, what it means, and how it is used. Issue and
pull request text is written in English.

## Type

| Label | Meaning |
|---|---|
| `bug` | Something isn't working as expected |
| `enhancement` | New feature or request |
| `documentation` | Improvements or additions to documentation |
| `question` | Further information is requested |
| `help wanted` | Extra attention is needed; contributions welcome |
| `good first issue` | Good for newcomers |
| `accessibility` | Barrier affecting people with disabilities |

## Priority (P0 to P3)

| Label | Meaning |
|---|---|
| `P0` | Emergency: data loss, security bypass, crash loop, or unusable extension |
| `P1` | High: blocks planned work, needs attention soon |
| `P2` | Medium: normal priority |
| `P3` | Low: nice to have |

## Status

| Label | Meaning |
|---|---|
| `status: blocked` | Blocked by something else |
| `status: in progress` | Work is underway |
| `status: ready to merge` | Approved and ready to merge |
| `status: merged` | Already merged |
| `status: wontfix` | Will not be addressed |

## Impact

| Label | Meaning |
|---|---|
| `impact: security` | Spotify session, credentials, or extension permissions at risk |
| `impact: data-loss` | Can lose, corrupt, or silently drop saved tracks or the local activity log |
| `impact: availability` | Stops saving, hangs, or crashes the player page |
| `impact: ux-blocker` | User cannot complete save, undo, or retry and gets no visible feedback |

## Area

| Label | Meaning |
|---|---|
| `area: extension` | Content script, background worker, options page, or bundle |
| `area: e2e` | Browser matrix, live Spotify runs, or proof artifacts |
| `area: docs` | README, ADRs, guides, or other documentation |
| `area: ci` | Workflows, gates, rulesets, or repository automation |

## Other

| Label | Meaning |
|---|---|
| `↩️ regression` | Was working before and now fails |
| `dependencies` | Pull requests that update a dependency |
| `github_actions` | Pull requests that update GitHub Actions |
| `javascript` | Pull requests that update JavaScript dependencies |
| `duplicate` | This issue or pull request already exists |
| `invalid` | This doesn't seem right |
| `wontfix` | This will not be worked on |

> Maintained by repo-standardizer: keep in sync whenever labels change.
